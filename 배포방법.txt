VOIDROLL : RENEWAL — Google Cloud(Cloud Run) 배포

1) console.cloud.google.com 에서 오른쪽 위 [Cloud Shell 활성화] 버튼(>_)을 누릅니다.
2) Cloud Shell 창의 [⋮] → [업로드] 로 이 zip 파일을 올립니다.
3) 아래 한 줄을 붙여넣고 엔터:

unzip -o voidroll-renewal.zip -d voidroll && cd voidroll && gcloud run deploy voidroll --source . --region asia-northeast3 --allow-unauthenticated

   (처음 한 번은 API 사용 여부를 물으면 y 를 누르세요)
4) 끝나면 나오는 Service URL 이 게임 주소입니다. 폰에서 열면 됩니다.

다시 올릴 때도 3번 한 줄만 다시 실행하면 같은 주소에 새 버전이 올라갑니다.
진행 상황은 각 기기 브라우저에 저장되며, 설정 → 저장 코드로 옮길 수 있습니다.
